# SONORA

Адаптивный магазин физических музыкальных носителей, собранный по текстовому экспорту макета Figma.

## Запуск

```bash
npm ci
npm run dev
```

Для проверки релизной сборки: `npm run build`.

Главная страница доступна по `/index.html`, полный каталог — по `/shop.html`, раздел винила — по `/shop.html?format=Vinyl`. Фильтры, поиск, сортировка, избранное, корзина и модальные статьи работают в браузере. Корзина и адреса из формы подписки сохраняются только на этом устройстве. Для приема платежей и отправки писем нужен подключенный сервер и соответствующие сервисы.

В текстовом экспорте Figma не было самих изображений и файлов шрифтов; декоративные изображения сейчас воссозданы средствами CSS. Для точного совпадения с макетом замените их оригинальными ассетами из Figma.
