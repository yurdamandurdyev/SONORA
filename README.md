# SONORA

Адаптивный магазин физических музыкальных носителей, собранный по текстовому экспорту макета Figma.

## Запуск

```bash
npm ci
npm run dev
```

Для проверки релизной сборки: `npm run build`.

Главная страница доступна по `/index.html`, полный каталог — по `/shop.html`. Разделы носителей открываются через `/shop.html?format=Vinyl`, `/shop.html?format=CD` и `/shop.html?format=Cassette`. Фильтры, поиск, сортировка, избранное, корзина и модальные статьи работают в браузере. Корзина и адреса из формы подписки сохраняются только на этом устройстве. Для приема платежей и отправки писем нужен подключенный сервер и соответствующие сервисы.

Шрифты включены в проект локально. Иллюстрации первых экранов Shop, Vinyl, CD и Cassette сохранены в `public/illustrations/` как близкие восстановленные версии присланных изображений. Это не исходные PNG из Figma: для пиксельного совпадения их можно заменить оригинальными файлами с теми же именами. Обложки товаров пока воссозданы средствами CSS.
